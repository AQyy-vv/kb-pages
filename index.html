## 1. 账号类问题

### 1.1 账号丢失

#### 1.1.1 未绑定第三方账号丢失

| 项目 | 内容 |
| --- | --- |
| **场景定义** | 玩家来信表示不记得账号 / 无法找到之前的游戏进度等。 |
| **处理流程** | 处理主线：定位目标账号 → 引导尝试登录 → 验证玩家信息 → 建立新的小号 → 转移前提醒 → 申请账号迁移。<br>**1. 定位目标账号**：询问账号信息（角色ID、区服和角色名、通行证ID）；查询定位账号（游戏运营后台-玩家中心-玩家信息-玩家信息管理）。<br>**2. 引导尝试登录**：查询绑定情况（游戏运营后台-账号绑定查询）；若定位到的玩家丢失账号已绑定第三方账号，提醒玩家绑定的账号类型，引导尝试自主登录。（注：玩家说自己不记得账号，且追问账号信息，上报组长，确认可以告知，再行回复。）若玩家仍然表示不记得账号，继续后续流程。<br>**3. 验证玩家信息**：询问验证信息，核验玩家身份，确认账号归属。可用验证信息包括：角色创建时间、首次充值订单、最后的充值订单、常用登录IP、常用登录设备码、S+英雄、角色等级、英雄星级、VIP等级、城市养成细节。（注：第三类验证信息需综合判定，玩家的好友信息不可用于身份验证；验证信息必须是玩家隐私信息并且能在后台查询到的信息；无法判断，上报组长。）<br>**4. 建立新的小号**：引导玩家在与丢失账号（老号）同区服（含合服前区服）新建账号（小号），并提供小号的角色名、角色ID、通行证ID。（注：代号A不需要在同区服建小号，只要玩家有其他的账号即可；位面2暂不涉及合服情形。）<br>**5. 转移前提醒**：提醒玩家下线，告知玩家账号转移期间将会封号，转移操作结束后将会解封；后台查询确认玩家下线状态。（说明：角色迁移时，玩家的角色必须下线且为封号的状态，若是角色在线会导致迁移失败、数据回流。）<br>**6. 申请账号迁移（转移）**：申请账号迁移；整理客诉情况，上报组长，提醒审批；组管理确认客诉情形，封禁玩家账号，通过申请，完成迁移后解封玩家账号。（注：申请时，需确保原角色ID（丢失账号）和目标账号ID（新建小号）填写正确，千万不要填反！）<br>**权限说明**：一线无封禁权限，但有申请账号迁移权限，按流程查询核实后，整理资料上报，自行申请账号迁移，后续封禁操作由组管理协调完成。 |
| **参考口径** | 定位账号时向玩家索取：角色ID、区服和角色名、通行证ID。<br>已绑定第三方账号时：提醒玩家绑定的账号类型，引导尝试自主登录。<br>玩家追问账号信息时：需上报组长，确认可以告知后再行回复。<br>身份验证时：仅可使用玩家隐私且后台可查询到的信息（角色创建时间、首次/最后充值订单、常用登录IP、常用登录设备码、S+英雄、角色等级、英雄星级、VIP等级、城市养成细节），玩家好友信息不可用于身份验证；无法判断时上报组长。<br>转移前需告知：账号转移期间将会封号，转移结束后将会解封；需先下线并确认下线状态，否则会导致迁移失败、数据回流。 |

## 2. 消费类问题

### 2.1 充值未到账

#### 2.1.1 购买礼包未到账（充值未到账（游戏内））

| 项目 | 内容 |
| --- | --- |
| **场景定义** | 充值未到账（游戏内）：玩家在游戏内购买付费道具/礼包（钻石/道具购买→购买确认→拉起支付→苹果订单/谷歌订单），完成支付但未收到道具的情形。常见诱因：①税率（部分地区在含税价基础上额外加收政府税款，账户余额刚好满足定价时可能因需额外缴税而被拒付）；②汇率（不同币种支付存在差距，实际收款不足原定价，订单可能不到账）。 |
| **处理流程** | 1）询问玩家订单信息：需提供充值时间、礼包价格、礼包名称等；信息不足时向玩家索要该笔订单发票（已提供或后台可查的，不重复询问）。2）查询订单发货状态：游戏运营后台-交易中心-网上支付订单（创单时间筛选、平台中心-海外手游平台、选择对应游戏，一般用角色ID查询）；显示【支付失败】或【暂无数据】可能为未到账，显示【支付成功】则经"数据中心-游戏日志-BI-物品日志"确认物品是否到账。3）确认是否为红钻订单：红钻购买不在订单查询页显示，需经物品日志核实，若为红钻购买则确认物品获取/使用记录（红钻物品ID为"25"），告知玩家已到账并自行核查。4）引导玩家提供发票：苹果发票号"M"开头、谷歌发票号"GPA."开头；注意苹果可能多笔订单合并为一张发票，需后台逐笔核对再解释（已提供发票则跳过）。5）查询订单付款状态：苹果经冰川网络开放平台-自助订单检测工具，结果为【已付款】需补单；谷歌经谷歌商店官方后台输入订单ID查询，结果为【已付款/已处理】需补单；其他情况填问答表。特殊情况：结果为"付款待处理"时，请玩家提供支付成功截图，上报组长/小组长联系运营确认是否到账。6）协商补发红钻/道具：话术沟通，同意补发则补发红钻/道具，拒绝补发可上报组长；礼包内具体道具经游戏内对应礼包查询（或参考玩家提供的礼包信息/截图），无法确认时上报组长/小组长。7）邮件补发：游戏运营后台-运营中心-邮件-新增；收件人务必手动核对角色ID/名称/区服（默认所有角色，未修改会发至全服）；补发后@组管理，附客诉概况、沟通方案截图、补发内容对应游戏/网页截图、邮件补发道具及原因部分截图。 |
| **参考口径** | 亲爱的玩家：感谢您的耐心等待，我们需要标准订单收据来核查订单信息，请前往"苹果应用商店"→点击右上角用户头像→选择iTunes账户→向下滚动选择"购买历史记录"，根据订单金额与下单日期找到相应订单并点击，将订单详细信息页面截图发送给我们，期待您的回复。（沟通中不得出现第三方代币"红钻/银票"名称，可用道具/物品替代解释，但不得解释为可代替现金购买；不发第三方代币截图及带PAY字段的充值链接。）——《超能战争》游戏团队 |
| **注意事项** | 延迟到账：苹果/谷歌订单可能延迟，玩家付款后较短时间即反馈未到账时，先建议等待24小时，仍未到账再按流程补单。掉单补发后玩家称【未收到道具】：查邮件发送记录并提醒查阅、确认游戏语言并引导切换查收、引导一键领取所有邮件并提供截图核对物品获取情形；最终仍未收到，与值班小组长/组长确认是否补发。 |

#### 2.1.2 代币充值未到账（充值未到账（第三方））

| 项目 | 内容 |
| --- | --- |
| **场景定义** | 充值未到账（第三方）：玩家通过第三方渠道充值红钻/银票（游戏内充值入口或网页充值入口），完成支付但未收到红钻/银票的情形。主要第三方支付渠道包括Terminal 3（T3，主要接入渠道）、Mycard（台湾主要渠道）、Razer、PayerMax、Xsolla、Adyen等。 |

## 3. BUG类问题

> **通用说明**：BUG 类客诉均遵循「判断是否已知BUG → 判断是否为BUG → 分情形处理（新BUG / 非BUG / 疑似BUG）」的主流程。

### BUG 处理流程（通用）

**第一步：判断是否为已知BUG**

*   查询 **BUG表**
    
    *   **是**（已知BUG）：按照 BUG表中的反馈回复玩家
        
    *   **否**：进入下一步
        

**第二步：判断是否为BUG**

*   向玩家索要 **截图 / 视频**
    
*   填写 **问答表**
    
*   注意事项：
    
    1.  填写问答表之后，小组长原则上需在 **1小时内** 答复；若等待时间超过 1小时，需在群里提醒，保持跟进
        
    2.  小组长可能会在问答表中要求引导玩家提供 **日志**；若需要，则需引导玩家提供并复制地址上报
        

**第三步：分情形处理**

| 情形 | 处理动作 |
| --- | --- |
| **确认是BUG** | 问答表：明确回复是BUG / BUG表：按照反馈回复玩家 |
| **确认非BUG** | 填写问答表，按照反馈回复玩家 |
| **疑似BUG、无法确认** | 添加 Pending 标签，按下方「疑似BUG跟进节奏」处理 |

**疑似BUG跟进节奏（Pending）**

| 时间 | 动作 |
| --- | --- |
| 当天 | 回复玩家需要时间进行调查，仅回复 |
| 第二天 | 回复玩家仍需时间进行调查，仅回复 |
| 第三天 | 根据是否补偿回复玩家，关闭工单 |

> 注：玩家会话超过 48 小时的时候，删除 Pending 标签会导致会话立即关闭，实际处理时，Pending 标签无需删除。

**疑似BUG关单回复思路**

*   **不补偿回复思路**：亲爱的玩家，问题仍在调查中，目前预计需较长时间，请您放心，我们会持续进行关注。与此同时，本次会话将被关闭，如果您仍有其他疑问，欢迎随时再次来信，感谢您的理解和耐心。
    
*   **可补偿回复思路**：亲爱的玩家，问题仍在调查中，目前预计需较长时间，抱歉给您带来了不佳的游戏体验，我们为您特别申请了XXX补偿，希望您能感受到我们的诚意。我们会不断努力完善游戏，与此同时，本次会话将被关闭，如果您仍有其他疑问，欢迎随时再次来信，感谢您的理解和耐心。
    

**注意**

*   疑似BUG情形需添加 BUG 标签，若确认不是BUG，再进行修改，日报表也遵循此规则
    
*   处理BUG类客诉时，需及时安抚、致歉，并持续保持跟进状态
    
*   玩家因BUG情绪激动 / 影响较大，可申请补偿，申请确认前不得讨论申请补偿事宜
